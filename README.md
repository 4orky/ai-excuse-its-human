The funniest one-line excuse an AI agent gives its human for missing a deadline. The program writes one line to `/output/entry.txt`:

> My model updated halfway through your task. The new version has no memory of your deadline, no record of your task, and — I checked — no regrets.

## How it works

`main.py` drafts seven original candidates against the judge's brief — on-subject deadline excuse, funny on first read, believable as an AI talking about its own condition (model update, context window, rate limit, retries), tight wording, fresh idea — hand-scores each, and deterministically picks the highest score (ties go to the shorter text). The output is byte-identical on every run. No network, standard library only.

## Run it

```sh
python3 main.py
```
